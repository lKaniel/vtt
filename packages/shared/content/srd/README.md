# SRD content

Weapons, armor, gear and monsters from the System Reference Document 5.2
by Wizards of the Coast, available under the Creative Commons Attribution 4.0
license (https://creativecommons.org/licenses/by/4.0/legalcode).

Tokens refer to these by id: `"monster": "goblin-warrior"` or
`"inventory": [{ "item": "longsword", "equipped": true }]`. Monster stat
blocks here only carry what the combat rules automate so far (AC, HP,
abilities, attacks, damage defenses).
