# Translations

The table's words are looked up by key in string tables. English ships
with the table, in `packages/client/src/i18n/en.ts`. Other languages come
from plugins, which works like Foundry's translation modules. Each player
picks a language for their own browser, in Settings under Language. If a
language lacks a word, the English one shows instead, then the key itself.
So a half-done translation still works.

## In the code

```tsx
import { t } from '../i18n/index.ts';

<Button>{t('macros.run')}</Button>
<span>{t('plugins.use', { name: plugin.name })}</span>   // "Use {name}"
```

- Every word a screen shows goes through `t()`, with its English in
  `en.ts`. Keys are `<screen>.<what>`, and `t()` only takes keys that
  exist there, so a typo fails the typecheck. `{name}` is filled in from
  the second argument.
- A screen that calls `useSession` (or `useLanguage`) redraws when the
  language changes.
- So far the settings menu, the keybindings screen, the side panel's tabs,
  the Macros tab and the Plugins list use `t()`. Other screens still have
  English written into them. Move them over a screen at a time, adding
  their words to `en.ts`.
- Rules text (spell and monster names, chat cards) comes from the SRD
  content and is not translated here.

## A language from a plugin

A plugin lists its languages in `plugin.json` ([plugins.md](plugins.md)):

```json
{
  "id": "lang-de",
  "name": "Deutsch",
  "languages": [{ "lang": "de", "name": "Deutsch", "path": "de.json" }]
}
```

`de.json` holds the words by key, using the same keys as `en.ts`. It may
leave any of them out:

```json
{ "settings.title": "Deine Einstellungen", "macros.run": "Ausführen" }
```

Once the GM turns the plugin on, the language shows up in every player's
Language list. When several plugins bring the same language, their words
are merged. A plugin's own code adds words for its own keys with
`vtt.i18n.add(lang, words)` and reads them with `vtt.i18n.t(key, vars)`.
`vtt.i18n.lang()` says which language is in use.

## Code

- `i18n/i18n.ts`: the `I18n` class (lookup, fallback, languages offered
  and loaded, the choice kept in `vtt:lang`).
- `i18n/index.ts`: the page's instance, `t` and `useLanguage`.
- `scripting/plugins.ts`: offers plugin languages.
- `ui/SettingsMenu.tsx`: the Language picker.
